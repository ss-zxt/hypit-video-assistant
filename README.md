# Hypit视频复刻助手

**Windows 本地视频拆解助手**：粘贴一条视频链接（或选一个本地视频），它自动取片、拆帧，
用**你自己电脑上的本地视觉模型**逐帧读图，生成一份分镜拆解初稿 `DRAFT_NOTES.md`。
全程在本机运行，不把视频发给任何云端服务。

取片引擎是 yt-dlp（经 omniget-cli 调用），**不止 TikTok**：它支持上千个站点，
YouTube、Bilibili、Instagram、X 等的链接都能直接粘。各站点实测情况：
TikTok 最稳；Bilibili 免登录可下到 1080p；YouTube 视网络与登录状态而定，
部分视频需要 cookies；抖音需要先从浏览器导入 cookies 才能下（暂未内置一键导入）。
脚本和界面里出现的"TikTok"只是名字和文案，下载逻辑对所有链接一视同仁。

> **免费版说明**：本助手是**免费版**，只能做到"拆解出提示词"这一步——产出
> 拆解初稿 MD 文件，**本身不生成视频**。把生成的 MD 文件上传给其他智能体
> （如 Muse），由对方生成视频；如果想直接生成视频，需要另行订阅
> Hypit 的相关服务。

## 项目说明

短视频复刻的第一步是"拆解"：把原片按时间轴看懂——每个时间段画面里有什么、
镜头怎么动、节奏在哪。这一步费时费眼。本助手把这步流水线化：

```
链接 / 本地视频
   → ① 取片（omniget-cli + yt-dlp 下载，或直接用本地文件）
   → ② 拆帧归档（Hypit：每 0.5 秒一帧的拼图 + 参考包）
   → ③ 逐图读图（本地 Ollama 视觉模型，一张拼图一份笔记，逐份落盘）
   → ④ 汇总成 DRAFT_NOTES.md 初稿
```

装好的组件（全部来自官方来源，安装时做 SHA-256 校验）：

| 组件 | 用途 | 版本 |
|---|---|---|
| Hypit（skill + CLI） | 拆帧、拼图、参考归档 | 0.3.1 |
| Ollama | 本地模型运行（已有安装会自动复用） | 0.40.14 |
| qwen3-vl（视觉模型） | 逐图读图，档位按硬件自动选（见下） | 按硬件 |
| FFmpeg | 视频处理 | 8.1.2 |
| omniget-cli + yt-dlp | 取片 | 0.14.0 / 2026.10.26 |

**定位与局限（务必先读）**：本地小模型的**逐格笔记是可用的原料**，但它自己写的
"汇总拆解"经常会编造内容（实测多次全盘不可信），所以汇总只作参考、不能直接当成品。
正确用法：把初稿当原料，交给人或更强的模型核对原片后写成品提示词——这正是本助手的
设计分工。它替你省的是"逐帧看片记笔记"的时间，不替你做最终判断。

**隐私**：拆解全程离线在本机进行；联网只发生在装组件/拉模型和下载你给的视频时。

## 系统要求

- Windows 10 / 11（64 位）
- 内存 ≥ 8 GB（决定模型档位，见下）；硬盘预留约 10 GB
- 有独立显卡更好（读图快很多），没有也能用（纯 CPU，慢一些）

模型按硬件自动选档：

| 条件 | 模型 |
|---|---|
| 内存 ≥ 32 GB 或显存 ≥ 16 GB | qwen3-vl:14b 级 |
| 内存 ≥ 16 GB 或显存 ≥ 8 GB | qwen3-vl:8b 级 |
| 内存 ≥ 8 GB | qwen3-vl:4b 级（instruct） |
| 更低 | 回落小模型（读图质量有限） |

注：无独显的大内存机器跑大模型是纯 CPU 推理，能跑但慢，属正常现象。
- **云电脑 / 虚拟机（无显卡、不能开虚拟化）可以装**：全套都是原生
  Windows 程序（PowerShell + 本地 exe），不依赖 WSL / Docker /
  Hyper-V，不用管理员权限（装在用户目录）。这类机器唯一要先手动
  装的是 Node.js ≥ 22.15（官网 LTS 版）。16 GB 内存会自动选 8B 级
  模型，纯 CPU 读图偏慢，建议安装时指定 4B：
  `powershell -ExecutionPolicy Bypass -File .\windows\install.ps1 -Model qwen3-vl:4b-instruct`


## 安装步骤

1. 下载本仓库 ZIP 并解压到任意文件夹（路径随意，D 盘更好）。
2. 双击 **`windows\install.bat`**，等它跑完。已装过的 Ollama 会直接复用，
   不会覆盖；每一步都有中文提示，失败会停下来告诉你原因。
3. 双击 **`windows\verify.bat`** 做验收：看到 **ALL CHECKS PASSED** 就是装好了
   （共 11 项，含一次真实推理冒烟测试）。
4. 卸载：运行 `windows\uninstall.ps1`（PowerShell），只删本助手装的东西，
   不碰你的 Ollama 本体和数据文件夹。

小提示：拉模型时如果你的代理把 Ollama 官方仓库重定向到了内网地址，
Ollama 会拒绝下载——这是它的安全策略，换个网络环境或已有模型时在安装时
指定 `-Model <已有模型名>` 即可跳过。

## 使用方法

### 图形界面（推荐）

1. **首次**：双击 `windows\assistant\video-draft-gui.bat` 打开界面。
   打开后，仓库根目录会自动生成带图标的快捷方式「**Hypit本地助手**」。
2. **之后**：一直双击根目录的快捷方式即可。启动全程**没有黑框**，
   任务栏里只有带应用图标的窗口本身。
3. 在输入框**粘贴视频链接**（或点「选文件...」选本地视频），
   点「**开始生成初稿**」，日志区实时显示进度；中途可点「停止」，
   已读完的拼图笔记会保留在项目文件夹里。
4. 跑完后下方三个按钮亮起：
   - **打开初稿 DRAFT_NOTES.md**：直接打开初稿；
   - **打开项目文件夹**：看拆帧、逐格笔记和归档；
   - **复制MD文件**：一次复制两种格式——粘贴到聊天框是初稿全文，
     粘贴到文件夹是 MD 文件本身（方便把初稿发给 AI 或同事接着加工）。
5. 界面状态行会显示硬件情况：有独立显卡显示显卡型号，没有则提示
   "读图较慢（纯 CPU），请耐心等"。

文件夹挪位置后快捷方式会失效？再双击一次 `video-draft-gui.bat`，
它会按新路径自动把快捷方式修好。若根目录一直没出现快捷方式，
双击 `windows\assistant\create-shortcut.bat`，它会停住窗口并打印
快捷方式实际写到了哪个路径。

### 命令行

双击 `windows\assistant\video-draft.bat`，按提示粘贴链接即可；
也可以把视频文件**拖到** `video-draft.bat` 上直接开跑。

### 数据与输出在哪

- 有 D 盘时默认落在 **`D:\HypitData`**（没有则在用户目录）；
  想改位置：设置环境变量 `HYPIT_DATA_DIR` 指向你的文件夹。
- 下载的视频：`<数据目录>\downloads\tiktok`
- 每个视频一个项目文件夹：`<数据目录>\projects\<名称>`，里面有
  `DRAFT_NOTES.md`（初稿）、逐格笔记、帧图拼图和原片归档。

## 常见问题

- **读图很慢**：无独显时纯 CPU 读图，一张拼图几分钟属正常；
- **任务管理器里有 GPU、界面却显示"纯 CPU"**：Ollama 只支持
  NVIDIA（CUDA）/ AMD（ROCm）等主流生态的显卡加速；摩尔线程等
  国产显卡（如移动云电脑的 S3000）目前不能被 Ollama 调用，读图
  确实是纯 CPU 跑的，界面这样显示是对的，不是识别错误。

  界面里的完成优先策略会自动把难读的拼图切半、缩小重试，不会卡死。
- **汇总段和逐格笔记对不上**：以逐格笔记为准（见"定位与局限"），汇总仅供参考。
- **安装时模型下载失败**：先检查网络/代理；或先装好任意 qwen3-vl 模型，
  再重跑安装并指定 `-Model`。
- **窗口打开了但任务栏图标不对**：用最新版覆盖后关掉旧窗口重开；
  新版给窗口注册了独立应用标识，不再显示 PowerShell 图标。
